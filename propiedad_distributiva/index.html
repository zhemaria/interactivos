La propiedad distributiva

Modelo de área, demostración paso a paso y práctica guiada

Idea central

Cuando un factor multiplica a una suma o a una resta encerrada entre paréntesis, ese factor multiplica a cada uno de los términos de adentro, no solo al primero.

a(b + c) = ab + ac

El signo que hay dentro del paréntesis se conserva en el resultado: si adentro se resta, en el resultado también se resta.

Por qué funciona: el modelo de área

Un rectángulo de altura 3 y base (x + 4) se puede partir en dos rectángulos. El área total es la misma, se calcule como se calcule.

3
base x3x
base 412

Diagrama: un rectángulo de altura 3 y base x más 4 se divide en dos partes. La primera tiene base x y área 3x. La segunda tiene base 4 y área 12.

Área de una sola pieza: 3(x + 4)  ·  Área por partes: 3x + 12  ·  Son iguales.
