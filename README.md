# interactivos · Interactivos de Matemáticas (colección anterior)

Colección de interactivos de Matemáticas de GEDparaHispanos anterior a la serie de interactivos por lección del repositorio [`algebra`](https://github.com/zhemaria/algebra). La mayoría quedó absorbida por esa serie, pero el repositorio **sigue publicado** porque las lecciones lo enlazan.

## En uso: no cambiar ni borrar
